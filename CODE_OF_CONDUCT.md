# Code of conduct

Tenured is hard on code and never on people. So is this project.

- Attack the defect, not the author. Every review comment here names a line, a failure, and a fix. None of them name a person's ability.
- Assume the other person is tired, on a deadline, and doing their best. Write the comment you would want to read at 2 a.m.
- No harassment, no slurs, no personal attacks, no publishing anyone's private information. This applies in issues, pull requests, discussions, and anywhere else the project is represented.
- Disagree with evidence. "This breaks when X" wins. "This is ugly" does not.

Maintainers may edit or remove comments that break these rules and may block repeat offenders. To report a problem, use GitHub's report feature on the comment or open a private security advisory if it involves something sensitive. Reports are read by the maintainer and handled within a week.
