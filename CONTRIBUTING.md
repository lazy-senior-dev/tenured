# Contributing

Until the first release, the most useful contribution is a repeat: an outage or bug that happened twice in the same codebase, with the commit that fixed it the first time and the commit that brought it back. Anonymise what you must; keep the shape. It becomes a benchmark case for Tenured.

Rules of the house are the same as grumpy-reviewer: plain conventional commits, no emoji, Node 20 or newer, no runtime dependencies, and commit as yourself.
